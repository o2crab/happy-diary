# Happiness Spiral アプリ

## 提供するサービス
幸せな暮らしを確立するためのツールを提供する。
具体的には、もっと幸せに生きたいのに幸せに過ごす方法かわからない人が、仮説検証サイクルを回しながら自分にとっての幸せな暮らし方を確立するための機能をwebアプリとして提供する。提供する機能は次の通り：仮説と検証方法の登録、日々の検証結果の記録、仮説検証過程の振り返り、過去の仮説検証サイクルの閲覧。

## 起動手順

[mise](https://mise.jdx.dev/) を導入したうえで、次を実行する。

```bash
mise trust
mise install
mise run setup
lefthook install
mise run dev
```

ブラウザで <http://127.0.0.1:5173> を開く。
